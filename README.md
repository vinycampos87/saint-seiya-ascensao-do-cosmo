# Saint Seiya — Ascensão do Cosmo

## Demonstração web v0.6

Este repositório destina-se à publicação de uma demo **Canvas 2D independente**, criada para testar o Campo de Provas do Santuário.

**Status:** configuração inicial do GitHub Pages. A publicação do pacote completo de imagens, CSS e JS da demo ainda está em andamento; não considere a demo pronta apenas pela presença de `index.html`.

### GitHub Pages
Em **Settings → Pages → Build and deployment**, escolha **Deploy from a branch**, `main`, pasta `/(root)`, e salve.

Quando todos os arquivos estiverem presentes, o endereço será:

https://vinycampos87.github.io/saint-seiya-ascensao-do-cosmo/

### Teste local
A versão de teste produzida anteriormente contém HTML, CSS, JS, 38 atlas e a arena 4K. É um protótipo web independente, não o projeto Phaser/React original.

*Projeto de fã não oficial; personagens e universo de Saint Seiya pertencem aos respectivos detentores de direitos.*
